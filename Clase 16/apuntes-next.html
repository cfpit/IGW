▲ Next.js

Apuntes de Next.js

Guía esencial de instalación, configuración, acceso a documentación y primeros pasos (Hola Mundo)

1. ¿Qué es Next.js y en qué se diferencia de React puro?

React es una biblioteca para construir interfaces de usuario que corre típicamente del lado del cliente (en el navegador del usuario).

Next.js es un framework de React para producción creado por Vercel. Integra React pero añade arquitectura de servidor, enrutamiento basado en archivos, optimización automática de imágenes y fuentes, renderizado en servidor (SSR) y generación estática (SSG).

Característica React Puro (con Vite) Next.js (App Router)
Renderizado 100% en cliente (SPA / CSR). El navegador descarga todo el JS. Híbrido: Server Components por defecto + Client Components.
Enrutamiento (Routing) Manual mediante librerías externas (react-router-dom). Automático basado en estructura de carpetas (app/).
SEO (Buscadores) Más complejo (el HTML inicial viene prácticamente vacío). Excelente (el HTML viene renderizado desde el servidor).
Servidor de Desarrollo http://localhost:5173 http://localhost:3000

2. ¿Qué se debe instalar? (Requisitos Previos)

Para trabajar con Next.js necesitas tener instalado en tu computadora:

1) Node.js (Entorno de ejecución)

Next.js requiere Node.js 18.18.0 o superior (se recomienda la versión LTS actual).

🔗 Descarga oficial: https://nodejs.org/es (Elegir la versión marcada como LTS).

2) Verificación en la Terminal

Abre tu consola (PowerShell, CMD o Git Bash) y comprueba las versiones instaladas:

node -v
npm -v

3) Gestor de paquetes recomendado: pnpm

Al igual que aprendiste en React, si estás trabajando dentro de carpetas sincronizadas por OneDrive, el uso de pnpm es altamente recomendable para evitar llenar el disco y prevenir bloqueos de sincronización: 

# Instalar pnpm globalmente una sola vez (si no lo tienes):
npm install -g pnpm

# Verificar instalación:
pnpm -v
⚠️ Nota para PowerShell en Windows: Si al ejecutar npm o pnpm recibes el error "la ejecución de scripts está deshabilitada en este sistema (about_Execution_Policies)", ejecuta en PowerShell como Administrador:
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
O también puedes invocar el comando directamente como npm.cmd o pnpm.cmd.

3. ¿Cómo acceder a la Documentación Oficial en la Web?

La documentación de Next.js es una de las más completas del ecosistema web. Puedes acceder a ella a través de estos enlaces clave:

  • 🌐 Sitio Web Oficial: https://nextjs.org — Página principal con novedades, características y casos de uso.
  • 📖 Documentación Oficial (Next.js Docs): https://nextjs.org/docs — Guías completas de instalación, routing, fetching de datos, estilizado y despliegue.
  • 🎓 Tutorial Interactivo Oficial (Next.js Learn): https://nextjs.org/learn — Curso guiado paso a paso con ejercicios prácticos para aprender desde cero.
  • 📁 Ejemplos Oficiales en GitHub: github.com/vercel/next.js/examples — Cientos de proyectos de ejemplo con Tailwind, autenticación, bases de datos, etc.
💡 Consejo crucial en la documentación: Asegúrate de que el selector superior en la web de docs esté en App Router (la arquitectura actual recomendada) en vez de Pages Router (la arquitectura anterior).

4. Creación de Proyectos en Next.js

Next.js provee la herramienta oficial create-next-app, la cual configura automáticamente todo el entorno.

Método A: Asistente Interactivo (Recomendado)

Sitúate en la terminal dentro de tu carpeta next y ejecuta:

# Con npx (npm):
npx create-next-app@latest

# O con pnpm (más rápido y ligero):
pnpm create next-app

Preguntas del Asistente y Opciones Recomendadas:

✔ What is your project named? … proyecto1

✔ Would you like to use TypeScript? … No (o Yes si prefieres tipado)

✔ Would you like to use ESLint? … Yes

✔ Would you like to use Tailwind CSS? … No (o Yes si usarás Tailwind)

✔ Would you like your code inside a `src/` directory? … Yes (mantiene el proyecto ordenado)

✔ Would you like to use App Router? (recommended) … Yes

✔ Would you like to use Turbopack for `next dev`? … Yes (compilación ultrarrápida)

✔ Would you like to customize the import alias (@/*)? … No

🚀 1. Would you like to use App Router? (recommended) → Yes

¿Qué es? Es el motor moderno de enrutamiento y renderizado de Next.js.

  • Pages Router (antiguo/legado): Guardaba las páginas en pages/. Todo se procesaba de forma tradicional y requería configuraciones complejas.
  • App Router (moderno / actual): Organiza la app en src/app/. Incluye React Server Components por defecto (el servidor envía el HTML ya armado, lo que hace la web mucho más rápida y con mejor SEO) y permite layouts fijos sin recargar la pantalla.
  • ¿Por qué responder Yes? Porque es el estándar oficial de Next.js y toda la documentación moderna está basada en él.

🔗 2. Would you like to customize the import alias (@/*)? → No

¿Qué es un "import alias"? Es un atajo para no tener que escribir rutas relativas largas y confusas como ../../../components/Boton.

  • El símbolo @/ apunta directamente a la raíz de tu código (src/).
  • Sin importar cuán profundo esté un archivo, puedes importar fácilmente con: import Boton from '@/components/Boton'.
  • ¿Por qué responder No? Porque Next.js te pregunta "¿Deseas personalizar (cambiar) el alias por otro símbolo?". Al responder No, le dices que mantenga el estándar @/*, que es el más cómodo y universal. (Si respondes Yes, tendrías que inventar tú otro prefijo como ~/* o #/*).

Método B: Creación Rápida en una sola línea (Sin preguntas)

Si quieres que se cree al instante sin responder cada opción manualmente:

# Con npx (npm tradicional):
npx create-next-app@latest proyecto1 --js --no-tailwind --eslint --app --src-dir --import-alias "@/*"

# ⚡ ULTRA RÁPIDO (Usando pnpm para no esperar minutos):
pnpm create next-app proyecto1 --js --no-tailwind --eslint --app --src-dir --import-alias "@/*" --use-pnpm
⚡ ¿Por qué es tan lento npx y cómo acelerarlo al máximo?

Si notas que la creación del proyecto se queda colgada durante varios minutos en "Installing dependencies...", se debe a dos motivos:

  1. El bloqueo de OneDrive (El principal culpable): Tu carpeta está dentro de OneDrive. Cuando npm descarga las librerías, crea más de 40.000 archivos diminutos en node_modules. OneDrive intenta inspeccionar y sincronizar cada uno a la nube en tiempo real, congelando el disco.
    👉 Solución: Haz clic derecho en el ícono de la nube de OneDrive en tu barra de tareas y elige "Pausar sincronización" (por 2 horas) mientras creas tus proyectos.
  2. Usa siempre el motor pnpm: Como ya tienes instalado pnpm en tu equipo, úsalo agregando la bandera --use-pnpm. pnpm no descarga archivos repetidos; reutiliza copias globales ya guardadas en tu disco y crea el proyecto en 15 a 25 segundos en vez de 5 minutos.

Comandos del Proyecto

Una vez dentro de la carpeta del proyecto (cd proyecto1), los comandos principales son:

Comando (npm) Comando (pnpm) Descripción
npm run dev pnpm dev Inicia el servidor local de desarrollo en http://localhost:3000 con recarga rápida.
npm run build pnpm build Compila y optimiza la aplicación para producción.
npm run start pnpm start Inicia el servidor en modo producción (requiere previo build).
npm run lint pnpm lint Verifica errores y advertencias de código con ESLint.

5. Estructura de Carpetas en Next.js (App Router)

En React puro con Vite todo tu código vivía suelto dentro de src/. En Next.js, todo se organiza de forma más limpia e intuitiva dentro de la carpeta especial src/app/.

Explorador de Archivos — proyecto1
📁 proyecto1/
Carpeta raíz del proyecto
📁 public/
Archivos estáticos (fotos, iconos, json)
📁 src/
Código fuente
📁 app/
⭐ El corazón de tu app
📄 page.js
⭐ Tu página de inicio (equivale a App.jsx)
📄 layout.js
🧱 Esqueleto HTML base (<html> y <body>)
🎨 globals.css
Estilos CSS para todo el sitio
🖼️ favicon.ico
Ícono de la pestaña del navegador
⚙️ next.config.mjs
Configuraciones de Next.js
📦 package.json
Librerías y scripts de ejecución

Equivalencias Directas: Si ya sabes React...

En React (Vite) En Next.js (App Router) ¿Para qué sirve?
src/App.jsx src/app/page.js Es tu componente principal. Lo que pongas aquí es lo que se ve en la pantalla de inicio.
index.html src/app/layout.js Contiene las etiquetas <html> y <body> que envuelven todas las páginas.
src/index.css src/app/globals.css Los estilos generales que aplican a todo el sitio web.
public/ public/ Imágenes y recursos que se leen directamente en el navegador (ej: /foto.png).
react-router-dom Crear carpetas en app/ Next.js no necesita librerías para rutas; crea las páginas automáticamente según las carpetas.

Los 3 Archivos que vas a utilizar:

⭐ page.js

Tu pantalla visual: Es el componente React donde programas los textos, botones y formularios que verá el usuario.

🧱 layout.js

Tu molde o estructura: Se mantiene fijo. Es ideal si en el futuro quieres poner un menú de navegación o un pie de página que aparezca siempre.

🎨 globals.css

Tus estilos: Aquí defines fuentes, colores de fondo y clases CSS para usarlas en cualquier parte de tu aplicación.

💡 ¿Cómo se crean nuevas páginas? (Enrutamiento Automático)

En Next.js no instalas react-router-dom. Cada carpeta que creas dentro de src/app/ se convierte en una URL:

  • src/app/page.js ➔ Abre en: http://localhost:3000/ (Inicio)
  • src/app/contacto/page.js ➔ Abre en: http://localhost:3000/contacto
  • src/app/productos/page.js ➔ Abre en: http://localhost:3000/productos

6. Pasos para Generar el "Hola Mundo" (Ultra Rápido con pnpm)

En App.jsx de tu primer proyecto de React tenías simplemente <h1>Hola mundo</h1>. En Next.js con App Router, el archivo equivalente es src/app/page.js. Realizamos todo el proceso con pnpm para crearlo en segundos y evitar que OneDrive se sature:

Paso 1: Abrir la terminal en la carpeta next

Asegúrate de estar ubicado en la raíz de tu carpeta next:

cd "c:\Users\smata\OneDrive\Documentos\Nueva carpeta\igw\next"

Paso 2: Crear el proyecto proyecto1 con pnpm

Opción recomendada (directa en una sola línea y ultra rápida):

pnpm create next-app proyecto1 --js --no-tailwind --eslint --app --src-dir --import-alias "@/*" --use-pnpm

O si prefieres usar el asistente interactivo:

pnpm create next-app proyecto1 --use-pnpm
⚡ Respuestas recomendadas en el asistente:
TypeScript: No  |  ESLint: Yes  |  Tailwind: No  |  `src/`: Yes  |  App Router: Yes  |  Turbopack: Yes  |  Import alias: No

Paso 3: Entrar al proyecto

cd proyecto1

Paso 4: Modificar src/app/page.js

Abre el archivo src/app/page.js, borra todo el contenido de plantilla que trae por defecto y escribe: 

export default function Home() {
  return (
    <h1>Hola mundo</h1>
  );
}

Paso 5: (Opcional) Limpiar src/app/globals.css

Para quitar los estilos oscuros por defecto y dejarlo limpio como en React, abre src/app/globals.css y déjalo así: 

body {
  font-family: Arial, Helvetica, sans-serif;
  margin: 2rem;
}

Paso 6: Iniciar el servidor con pnpm

pnpm dev

Paso 7: Abrir en el navegador

Ingresa a 👉 http://localhost:3000 y verás tu Hola mundo en pantalla exactamente igual que en el primer proyecto de React.
