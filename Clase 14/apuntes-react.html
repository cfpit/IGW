⚛️ Apuntes de React

Guía de instalación, configuración, gestión de paquetes y consumo de datos locales

1. Instalación de Node.js

Descargar el instalador desde la web oficial: https://nodejs.org/es

👉 Elegir siempre la última versión LTS (Long Term Support / Soporte a largo plazo).

Verificación en la terminal

Abre tu terminal (PowerShell, CMD o Bash) y comprueba las versiones instaladas:

node -v
npm -v

2. Creación de Proyectos en React

Opción A: Instalación Global de CRA Obsoleta

Instala la herramienta en todo el sistema:

# 1) Instalación de React en forma global
npm install -g create-react-app

# 2) Creación del proyecto
create-react-app proyecto1

Opción B: Creación con npx Obsoleta

Crea el proyecto descargando la última versión temporal sin instalar globalmente:

# 1-2) Creación del proyecto
npx create-react-app proyecto1

# 3) Ejecución de la aplicación
cd proyecto1
npm start

Opción C: Usando Vite Recomendada

Es la forma estándar y ultra veloz actualmente.

# 1) Creación de la estructura del proyecto
npm create vite@latest proyecto1 -- --template react

# 2) Entrar a la carpeta, instalar y ejecutar
cd proyecto1
npm install
npm run dev
💡 Nota sobre npm install con Vite: Este comando es rapidísimo porque el node_modules que descarga es muchísimo más liviano y moderno que el que descargaba create-react-app.

Opción D: Usando pnpm Ahorro Máximo de Disco

Si creas múltiples proyectos de práctica y no quieres que cada uno duplique cientos de MB en tu disco: 

# 1) Instalar pnpm una sola vez de forma global
npm install -g pnpm

# 2) Crear proyectos nuevos con pnpm y Vite
pnpm create vite proyecto3 --template react
cd proyecto3
pnpm install
pnpm dev

Migrar proyectos existentes a pnpm:

  • Borra la carpeta node_modules pesada de tus proyectos ya creados.
  • Entra a cada uno y ejecuta:
# En proyecto1:
cd proyecto1
pnpm install

# En proyecto2:
cd ../proyecto2
pnpm install
⚠️ Beneficio con OneDrive: Al usar pnpm, las librerías se guardan centralizadas en tu disco local fuera de OneDrive, evitando que OneDrive colapse intentando sincronizar miles de archivos pequeños a la nube.

3. Consumo de Datos Locales (.json) en React

Para consumir datos desde un archivo local en lugar de una API remota, usamos el archivo frutas.json:

Archivo de datos: frutas.json

[
  {
    "codigo": 1,
    "descripcion": "papas",
    "precio": 12.33
  },
  {
    "codigo": 2,
    "descripcion": "manzanas",
    "precio": 54
  }
]

Método 1: En carpeta public/ (Con fetch y useEffect) Recomendada

Ubicación del archivo: proyecto3/public/frutas.json

Se lee directamente con fetch('/frutas.json') simulando una API:

import { useState, useEffect } from 'react';

function App() {

  const [articulos, setArticulos] = useState([])

  useEffect(() => {
    // Leemos el archivo desde la raíz del servidor público de Vite
    fetch('/frutas.json')
      .then((response) => {
        return response.json()
      })
      .then((articulos) => {
        setArticulos(articulos)
      })
  }, [])

  return (
    <div>
      <table border="1">
        <thead>
          <tr>
            <th>Código</th>
            <th>Descripción</th>
            <th>Precio</th>
          </tr>
        </thead>
        <tbody>
          {articulos.map(art => {
            return (
              <tr key={art.codigo}>
                <td>{art.codigo}</td>
                <td>{art.descripcion}</td>
                <td>{art.precio}</td>
              </tr>
            );
          })}
        </tbody>
      </table>
    </div>
  );
}

export default App

Método 2: En carpeta src/ (Importación directa sin fetch)

Ubicación: proyecto3/src/frutas.json

Importa los datos directamente en el componente sin peticiones asíncronas:

import { useState } from 'react';
import frutasData from './frutas.json';

function App() {

  const [articulos, setArticulos] = useState(frutasData)

  return (
    <div>
      <table border="1">
        <thead>
          <tr>
            <th>Código</th>
            <th>Descripción</th>
            <th>Precio</th>
          </tr>
        </thead>
        <tbody>
          {articulos.map(art => {
            return (
              <tr key={art.codigo}>
                <td>{art.codigo}</td>
                <td>{art.descripcion}</td>
                <td>{art.precio}</td>
              </tr>
            );
          })}
        </tbody>
      </table>
    </div>
  );
}

export default App

4. Estilos de Tailwind para la Tabla en App.css

Tailwind está pensado para usarse con clases en el JSX (className="..."), pero se pueden aplicar sus estilos a la tabla modificando únicamente src/App.css:

Caso 1: Replicar el diseño de Tailwind con CSS Puro Recomendada / Sin Instalar Nada

No requiere instalar paquetes ni configurar nada. Pega este contenido directamente dentro de src/App.css: 

/* Contenedor centrado */
body {
  font-family: system-ui, -apple-system, sans-serif;
  background-color: #f8fafc;
  display: flex;
  justify-content: center;
  padding: 2rem;
}

/* Tabla con diseño moderno estilo Tailwind */
table {
  width: 100%;
  max-width: 600px;
  border-collapse: collapse;
  background-color: #ffffff;
  border-radius: 8px;
  overflow: hidden;
  box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.1), 0 2px 4px -2px rgba(0, 0, 0, 0.1);
  border: 1px solid #e2e8f0;
}

/* Encabezados */
th {
  background-color: #f1f5f9;
  color: #475569;
  font-size: 0.75rem;
  font-weight: 700;
  text-transform: uppercase;
  letter-spacing: 0.05em;
  padding: 0.75rem 1.5rem;
  text-align: left;
  border-bottom: 1px solid #e2e8f0;
}

/* Celdas */
td {
  padding: 1rem 1.5rem;
  font-size: 0.875rem;
  color: #1e293b;
  border-bottom: 1px solid #f1f5f9;
}

/* Efecto hover al pasar el ratón por la fila */
tbody tr:hover {
  background-color: #f8fafc;
}

/* Quitar el borde inferior a la última fila */
tbody tr:last-child td {
  border-bottom: none;
}
💡 Consejo para App.jsx: Para que se luzca el nuevo diseño, quita el atributo border="1" de la etiqueta <table> en tu archivo App.jsx.

Caso 2: Usando Tailwind Oficial con la directiva @apply

Si prefieres usar Tailwind oficial en tu proyecto Vite, sigue estos 3 pasos:

1. Instalar dependencias en la terminal:

pnpm add -D tailwindcss @tailwindcss/vite

2. Configurar vite.config.js:

Importas @tailwindcss/vite y lo agregas en el arreglo plugins:

import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite' // 1. Importas el plugin

// https://vite.dev/config/
export default defineConfig({
  plugins: [
    react(),
    tailwindcss(), // 2. Lo agregas aquí
  ],
})

3. En src/App.css con @apply:

@import "tailwindcss";

table {
  @apply w-full max-w-md mx-auto bg-white rounded-lg shadow-md border border-gray-200 overflow-hidden;
}

th {
  @apply bg-gray-50 text-gray-500 text-xs font-bold uppercase px-6 py-3 border-b border-gray-200;
}

td {
  @apply px-6 py-4 text-sm text-gray-800 border-b border-gray-100;
}
